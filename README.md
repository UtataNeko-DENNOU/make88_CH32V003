## 🛠️ ハードウェア仕様・ピンアサイン

* **マイコン**: WCH `CH32V003F4P6`（32-bit RISC-V / TSSOP-20 / Flash 16KB / SRAM 2KB）

* **LEDマトリクス**: 8×8 ドット（1608サイズ SMD LED × 64個 / 1/8 ダイナミック点灯）

* **電源**: CR2032 コイン電池（3.0V）＋ 物理電源スイッチ（`SW1`）

* **入力**: プッシュタクトスイッチ（`PSW1`）

### GPIO ピン割り当て

| 機能 | 割り当てピン（順） | 論理・備考 | 
| ----- | ----- | ----- | 
| **行ピン（Row 0〜7 / 上→下）** | `PA1`, `PD7`, `PD6`, `PD5`, `PD4`, `PD3`, `PD2`, `PD0` | カソード側（LOW アクティブ）  ※`PA1` はリマップ、`PD7` は事前GPIO化が必要 | 
| **列ピン（Col 0〜7 / 左→右）** | `PC1`, `PC2`, `PC3`, `PC4`, `PC5`, `PC6`, `PC7`, `PA2` | アノード側（HIGH アクティブ）  ※`PA2` はリマップが必要 | 
| **プッシュスイッチ（PSW1）** | `PC0` | 内部プルアップ入力（LOW アクティブ） | 
| **SWD 書き込み端子（J2）** | `SWDIO (PD1)`, `3.3V`, `GND` | 3線接続（**※5V印加厳禁**） | 

## 💻 環境構築・書き込み手順

### 1. Arduino IDE のセットアップ

1. Arduino IDE の **「ファイル」→「基本設定」** を開き、「追加のボードマネージャのURL」に以下を追加します。

   ```
   https://github.com/openwch/board_manager_files/raw/main/package_ch32v_index.json
   
   ```

2. **「ツール」→「ボード」→「ボードマネージャ」** で `CH32` を検索し、**`CH32 MCU EVT Boards`** をインストールします。

3. 「ツール」メニューから以下のように設定します。

   * **Board**: `CH32V00x`

   * **Chip Series**: `CH32V003`

   * **CPU Frequency**: `24MHz (HSI)`（※ボタン電池駆動向けの省電力設定）

   * **Upload Method**: `WCH-SWD`

### 2. WCH-LinkE での書き込み（重要注意事項）

> \[!CAUTION\]
> **電源電圧は必ず「3.3V」を使用してください。**
>
> 本基板に 5V を供給すると LED 回路に過電圧がかかり破損の原因になります。

1. **WCH-LinkE のモード確認**: PC 接続時に本体上の **青色LEDが消灯（RVモード）** していることを確認してください（点灯している場合は ARM モードのため、`ModeSelect` ボタンを押しながら再接続または `WCH-LinkUtility` で `WCH-LinkRV` に切り替えます）。

2. **初回のみの事前準備**: 最初に `make88_CH32V003_matrix_PD7.ino` を書き込み、リセット端子（NRST）を `PD7`（Row 1）として解放してください。

3. **本編スケッチの書き込み**: その後、テストスケッチやスクロール完全版を書き込んで動作を確認します。

## 🔧 トラブルシューティング

* **2行目（Row 1）だけまったく点灯しない**

  * 出荷状態では `PD7` がリセットピン（NRST）になっています。先に `make88_CH32V003_matrix_PD7.ino` を書き込んで Option Byte を更新してください。

* **書き込み時にエラーが出る / デバッガが認識しない**

  * `WCH-LinkE` の配線（`SWDIO`, `3.3V`, `GND`）と、電源スイッチ（`SW1`）の状態、および WCH-LinkE が **RVモード（青LED消灯）** になっているか確認してください。

  * `PD7` を GPIO 化した後に書き込みが通らなくなった場合は、公式ツール `WCH-LinkUtility` の **「Target」→「Erase Code Flash」**（電源投入直後の接続）で初期化できます。
